# Cosmic Launcher

Minecraft Launcher + FPS-Boost Client (Tauri v2 + React + Three.js).

## Xem giao diện nhanh
    npm install
    npm run dev

## Build bằng GitHub
1. Đẩy toàn bộ thư mục này lên một repo GitHub (nhánh main).
2. Tab Actions -> chọn Build Windows / macOS / Android / iOS -> Run workflow.
3. Chờ xong, mở lần chạy, tải file ở mục Artifacts.

Icon được tự sinh trong workflow từ app-icon.png.
